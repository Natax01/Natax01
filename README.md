یک وب‌سایت فروشگاهی مدرن و کامل با طراحی زیبا و عملکرد پیشرفته

## ویژگی‌های سایت

### �️ عملکرد فروشگاهی

- JavaScript ES6+
- Local Storage برای ذخیره داده‌ها
- نمایش اطلاعیه‌های کاربری

## فایل‌های پروژه

```
├── index.html       # صفحه اصلی وب‌سایت
├── styles.css       # فایل استایل‌های CSS
├── script.js        # فایل جاوااسکریپت
└── README.md        # راهنمای پروژه
```

## نحوه اجرا

1. فایل `index.html` را در مرورگر باز کنید
2. وب‌سایت به صورت کامل اجرا خواهد شد

یا با استفاده از سرور محلی:

```bash
# با Python
python -m http.server 8000

# با Node.js (npx)
npx serve .

# سپس به آدرس http://localhost:8000 بروید
```

## تنظیمات قابل تغییر

### افزودن محصول جدید
در فایل `script.js` آرایه `products` را ویرایش کنید:

```javascript
{
    id: 7,
    title: "نام محصول",
    description: "توضیحات محصول",
    price: 1000000,
    image: "🎮",
    category: "دسته‌بندی",
    stock: 15,
    features: ["ویژگی 1", "ویژگی 2"]
}
```

### تغییر رنگ‌بندی
در فایل `styles.css` متغیرهای رنگ را تغییر دهید:

```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --accent-color: #ffd700;
}
```
