# 🎓 سایت معرفی مدرسه آینده‌سازان

یک سایت مدرن و responsive برای معرفی مدرسه با طراحی زیبا و کاربردی.

## ✨ ویژگی‌های سایت

### 🎨 طراحی و ظاهر
- **طراحی مدرن و زیبا** با استفاده از gradient و انیمیشن‌های جذاب
- **کاملاً Responsive** - سازگار با تمام دستگاه‌ها (موبایل، تبلت، دسکتاپ)
- **فونت فارسی Vazir** برای خوانایی بهتر متون فارسی
- **آیکون‌های Font Awesome** برای بهبود ظاهر
- **انیمیشن‌های CSS** برای تجربه کاربری بهتر

### 📱 بخش‌های سایت

1. **صفحه اصلی (Hero Section)**
   - معرفی مدرسه با شعار جذاب
   - دکمه‌های Call-to-Action
   - انیمیشن تایپ ماشین برای عنوان

2. **درباره ما**
   - چشم‌انداز و ارزش‌های مدرسه
   - آمار و ارقام با انیمیشن شمارنده
   - معرفی دستاوردها

3. **امکانات مدرسه**
   - آزمایشگاه علوم
   - کلاس کامپیوتر
   - کتابخانه
   - سالن ورزش
   - کلاس هنر و موسیقی

4. **معرفی اساتید**
   - پروفایل معلمان
   - تخصص و تجربه
   - مدارک علمی

5. **رویدادها و اخبار**
   - تقویم رویدادها
   - اخبار و اطلاعیه‌ها
   - برنامه‌های آتی

6. **تماس با ما**
   - اطلاعات تماس کامل
   - فرم ارسال پیام
   - آدرس و ساعات کاری

### 🚀 قابلیت‌های فنی

#### JavaScript Features
- **Navigation mobile** با منوی همبرگری
- **Smooth scrolling** برای لینک‌های داخلی
- **Intersection Observer** برای انیمیشن‌های اسکرول
- **Counter animation** برای آمار و ارقام
- **Form validation** و پردازش فرم تماس
- **Notification system** برای نمایش پیام‌ها
- **Parallax effects** برای بخش hero
- **Scroll to top button** برای راحتی کاربر

#### CSS Features
- **Flexbox & Grid** برای layout مدرن
- **Custom properties** برای مدیریت رنگ‌ها
- **Transitions & Animations** برای تعاملات روان
- **Media queries** برای responsive design
- **Box-shadow & Gradients** برای عمق بصری

### سفارشی‌سازی

#### تغییر اطلاعات مدرسه
```html
<!-- در فایل index.html -->
<h1>نام مدرسه شما</h1>
<h2>شعار مدرسه شما</h2>
```

#### تغییر رنگ‌های سایت
```css
/* در فایل styles.css */
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --accent-color: #ff6b6b;
}
```

#### اضافه کردن بخش جدید
```html
<section id="new-section" class="new-section">
    <div class="container">
        <!-- محتوای بخش جدید -->
    </div>
</section>
```
